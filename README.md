# Swarm Formation

# Run for simulation

```
To run with rviz2:
- `ros2 launch path_manager path_manager.launch.py rviz_simulation:=true`
```

To run with gazebo:
- `ros2 launch path_manager path_manager.launch.py`
```

# Run for real world

```
To run:
- `ros2 launch path_manager path_manager.launch.py real:=true`
```
