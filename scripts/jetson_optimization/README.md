# Jetson Optimization Scripts

This directory contains scripts for optimizing Jetson Orin performance for the swarm formation system.

## 📁 Contents

- `optimize_jetson.sh` - Main performance optimization script
- `monitor_performance.sh` - Real-time performance monitoring
- `jetson-optimizer.service` - Systemd service for automatic optimization
- `JETSON_OPTIMIZATION.md` - Detailed usage guide

## 🚀 Quick Usage

```bash
# From project root
./scripts/jetson_optimization/optimize_jetson.sh
./scripts/jetson_optimization/monitor_performance.sh

# Or navigate to directory
cd scripts/jetson_optimization
./optimize_jetson.sh
./monitor_performance.sh
```
